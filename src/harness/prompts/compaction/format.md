# Output Format

Use these Markdown headings in this order. Write (none) for an empty section.

```markdown
## Goal
[The user's goals]

## Constraints & Preferences
- [Requirements, preferences, and corrections]

## Progress
### Done
- [x] [Confirmed completed work]

### In Progress
- [ ] [Current work]

### Blocked
- [Unresolved blockers]

## Key Decisions
- [Decision and its reason]

## Next Steps
1. [The next action]

## Critical Context
- [Facts and references needed to continue]
```
